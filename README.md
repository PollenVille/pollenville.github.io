<div class='self-assessment'>
 <h4>Self-Assessment</h4>

 <p>This project was a chance for me to demonstrate my skills in developing a full-stack project from start to finish on my own. I chose to enhance this artifact because the original file was so simple. Originally, this program was a simple search function that looped through a map to find the user’s requested item. This program had no interface or database for the user to interact with and store items. </p>

 <p>In a previous course, we covered the development of a full-stack program from start to finish. That project walked us through spinning up a database using MongoDB and Postman for verification. Along with that knowledge from previous courses, I also used knowledge I’ve gained from projects and courses I’ve taken in my free time. By combining the knowledge I’ve gained, I've demonstrated my skills in full-stack web development. </p>

 <p>While this project didn’t require collaborating in a team environment, it is still important to practice these skills. Successful software development requires teamwork and collaboration of different roles and skills. Effective collaboration combines each team member's knowledge and perspective, enriching decision-making and the quality of the final product. To ensure I’m prepared to step into the computer science field, I must continue to practice these skills.</p>

 <p>This project was meant to combine multiple topics by enhancing a single artifact through various phases. These topics included data structures and algorithms, software engineering, database, and security. The first phase focused on software design and engineering by converting the code from C++ to JavaScript. This was also the phase when the initial HTML was implemented to build the site's frontend. The next phase is where I began porting the data to MongoDB to create the database. This phase required implementing schemas to recreate the data inventory as grocery store products. This approach.  This design is great for future scalability as it allows the product to be created in a simple, predefined way. The next phase was where everything was put together. This phase links the database, backend, and frontend together. The final program is a web application that can add, retrieve, and remove inventory from a product database. </p>
